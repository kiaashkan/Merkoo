# مرکو (Merkoo) — بات و مینی‌اپ لیست خرید تلگرام

> **English:** [README.md](README.md)

**مرکو** یک بات تلگرام و مینی‌اپ برای لیست خرید اشتراکی، کارهای انجامی و بانک قیمت شخصی است. روی Cloudflare Workers اجرا می‌شود و داده‌ها را در Durable Objects (با ذخیره‌سازی SQLite) نگه می‌دارد؛ بدون دیتابیس خارجی و بدون هیچ وابستگی زمان اجرا. از همان ابتدا دوزبانه است: **فارسی و انگلیسی**.

🤖 **بات زنده:** [@MerkooBot](https://t.me/MerkooBot)

## امکانات

- **بورد اشتراکی زنده** — لیست خرید را در مینی‌اپ بسازید، با حالت اینلاین به هر چتی بفرستید و آن را پین کنید. پیام پین‌شده هم‌زمان با اضافه، خریده، ویرایش یا حذف شدن آیتم‌ها، زنده به‌روز می‌شود.
- **خرید و کارها در یک بورد** — دو نوع لیست (آیتم‌های خرید و کارهای انجامی) با دسته‌بندی (پوشه)، تعداد، واحد، مقدار و قیمت.
- **بانک قیمت (کاتالوگ)** — قیمت هر محصول را یک بار ثبت کنید تا هنگام اضافه کردن دوباره‌ی همان آیتم، به‌صورت خودکار استفاده شود.
- **همکاران و سطح دسترسی** — بورد را با لینک دعوت به اشتراک بگذارید. مالک لیست مشخص می‌کند چه کسی اجازه ویرایش دارد، می‌تواند همکار را حذف یا مسدود کند و هر وقت بخواهد توکن دعوت را عوض کند. همه‌ی تغییرات در یک تاریخچه‌ی قابل مشاهده ثبت می‌شود.
- **افزودن سریع از داخل چت** — در چت بات، هر خط یک آیتم خرید است؛ اگر خط با `!` یا `task:` شروع شود، به‌عنوان کار انجامی اضافه می‌شود.
- **حمایت مالی** — در مینی‌اپ یک کد QR کیف پول TON برای حمایت داوطلبانه قرار دارد.

## امنیت

- داده‌ی `initData` تلگرام طبق مشخصات رسمی تلگرام با HMAC بررسی می‌شود (مقایسه‌ی زمان‌امن و پنجره‌ی تازگی ۳۰ دقیقه‌ای).
- توکن‌های نشست امضاشده به چت و به epoch اختصاصی هر کاربر متصل‌اند، پس دسترسی هر کاربر را می‌شود فوراً باطل کرد.
- وبهوک با یک توکن محرمانه که از توکن بات مشتق می‌شود محافظت می‌شود.
- خود Durable Object هنگام هر ذخیره، حقوق مالک / همکار / دعوت / ویرایش را دوباره بررسی می‌کند؛ به لایه‌ی API به‌تنهایی اعتماد نمی‌شود.
- محدودیت نرخ درخواست جداگانه برای هر IP، هر کاربر و هر بورد؛ سقف اندازه‌ی درخواست و اندازه‌ی لیست‌ها.
- هدر Content-Security-Policy سخت‌گیرانه با nonce اختصاصی هر درخواست؛ همه‌ی خروجی‌های نمایشی escape می‌شوند.
- **هیچ محرمانه‌ای در این ریپو نیست** — توکن بات فقط به‌صورت Secret روی کلودفلر نگهداری می‌شود.

## معماری

| فایل | نقش |
| --- | --- |
| `worker.js` | ورکر اصلی: وبهوک تلگرام، API مینی‌اپ و کلاس Durable Object به نام `MerkooBoardDO` (برای هر چت یک بورد، به‌همراه نمونه‌های `system_meta` و `app_analytics`). |
| `miniapp.js` | سند کامل و خودبسنده‌ی مینی‌اپ (HTML/CSS/JS) که ورکر اصلی در مسیر `/app` ارائه می‌کند. |
| `wrangler.toml` | تنظیمات ورکر اصلی (متغیرها و بایندینگ Durable Object). |

## راه‌اندازی

۱. با [@BotFather](https://t.me/BotFather) یک بات بسازید و برای آن یک نام کوتاه مینی‌اپ (Short Name) ثبت کنید (پیش‌فرض کد `app` است — متغیر `APP_SHORT_NAME`).

۲. ورکر اصلی را دیپلوی کنید و توکن بات را بگذارید:

```bash
npx wrangler deploy
npx wrangler secret put BOT_TOKEN
```

متغیر `BOT_USERNAME` را در `wrangler.toml` برابر نام کاربری بات خودتان بگذارید. آدرس وبهوک و دستورات بات در اولین درخواست به‌صورت خودکار تنظیم می‌شوند.
